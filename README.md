# C++ Programming Practice

## What is this?
The code associated with a preparation programme for competitive online assessments and technical interviews in C++. This uses a modular approach to cover different frequently-tested algorithms and patterns. Every module contains practice problems in **exercises** and some worked-through problems in **tutorials**. This coding practice is accompanied by an Anki deck for spaced repetition, which is not included here.

---
## Language
This programme uses C++17, avoiding newer versions to ensure compatibility with all assessment and interview software that may lack newer versions.

---
## Structure
**tutorials/**   contains worked-through problems.\
**exercises/**   contains solutions to practice problems.
